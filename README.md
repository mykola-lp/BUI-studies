## Structure

| Folder | Description |
|---|---|
| `hw0`–`hw7` | Homework assignments (layout/CSS projects), in order of completion |
| `js-homeworks` | Task descriptions for JavaScript homework (`.md` files, one per topic — functions, objects, arrays, DOM, events, fetch, gulp) |
| `webinar-code/HTML-CSS` | Code written/followed during live HTML/CSS webinar sessions (basics → box model → flex/grid → positioning → forms → animation → media queries → SCSS → first full project) |
| `webinar-code/JS` | Code written/followed during live JavaScript webinar sessions (basics → functions → objects → arrays → DOM/BOM → events → timers/localStorage → drag & drop → fetch/async → npm/gulp) |
| `webinar-code/cashflower-app` | Larger practice project — a finance-tracking app built with vanilla JS, SCSS, and Gulp |
| `webinar-code/firebase` | Practice project integrating Firebase |
| `figma` | Design files (`.fig`) used as references for each homework |
| `docs` | Course notes and reference material (properties, box model, flexbox/grid, document flow) with supporting images |

Each homework folder may contain its own README with task-specific notes.

## Tech

Vanilla HTML, CSS, and JavaScript throughout most of the coursework. Later webinar/practice projects (`cashflower-app`, `17--npm-gulp`, `12--scss-parcel`, `13--first-project`) introduce SCSS, Gulp, and npm-based build tooling as the course progressed.
